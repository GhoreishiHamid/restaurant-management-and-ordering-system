# Research-oriented roadmap

**Phase 1 (this patch):** browse the menu, register/login/logout, place orders, view own order history and details, seed data, and run feature tests.

**Phase 2:** implement staff/admin roles with authorization, menu CRUD, order-status transitions, validation tests, and a dashboard. Add clear screenshots and a diagram of the database schema.

**Phase 3:** build reproducible database performance experiments over 1,000 / 10,000 / 100,000 synthetic orders. Compare query plans and indexed versus unindexed queries, record p50/p95 response times, and publish environment/hardware details plus limitations. Do not claim performance improvements before measurement.

**Phase 4:** CI with GitHub Actions, code quality checks, architecture documentation, license, demo video, and a complete English README suitable for a master's research application.
